# 数学建模 F 题：算力约束下的大语言模型资源配置

本仓库对应本地 `数学建模26/F题/` 的内容，仓库根目录即 F题 文件夹。包含题目、完整附件、干净版数据说明、三人可分配的建模任务和 PDF 清洗工具。当前尚未实施模型 baseline。

## 从这里开始

1. 阅读[赛题正文](./算力约束下提升大语言模型能力的资源配置建模.docx)和[干净版数据说明](./数据说明_干净版.pdf)。
2. 查看[建模方案入口](./建模方案/README.md)与[三人分工与交接](./建模方案/三人分工与交接.md)。
3. 三人分别领取 [Baseline A/B/C](./建模方案/baselines/README.md) 中的一条完整方案，优先实现和验证前三问；第四问复杂度过高时可以先不做。
4. 更复杂的问题、[具体优化方向](./建模方案/优化方向/README.md)和[研究主线](./建模方案/02_优化方向与研究主线.md)均暂不分配，留待 baseline 完成后讨论。

## 下载完整数据

压缩的质量信号与原始语料（`*.jsonl.xz`）通过 Git LFS 保存，仓库内保持原文件名。GitHub 的普通 Git 单文件上限为 100 MiB，超限文件需使用 LFS 等大文件方式；本项目使用 LFS。[GitHub 官方说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)

安装 Git LFS 后执行：

```bash
git lfs install
git clone https://github.com/gilGAMEsh002/math_model_F.git
cd math_model_F
git lfs pull
git lfs fsck
```

建议用上述方式克隆；网页 ZIP 是否包含 LFS 实体取决于仓库设置，不应把 LFS 指针文本误当作数据文件。
