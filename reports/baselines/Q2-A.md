# Q2-A 报告：经典标度律 + 加性质量修正

- 所属 baseline：Baseline A
- 代码：`src/baselines/q2a/run.py`、`src/common/scaling.py`
- 配置：`configs/baselines/Q2-A.yaml`
- 结果：`artifacts/baselines/Q2-A/`
- 上游：`artifacts/baselines/Q1-A/mixture_predictor.json`、`p0.json`
- 运行：`python3 -m src.baselines.q2a.run --config configs/baselines/Q2-A.yaml`

## 1. 模型

```
L(N,D)     = E + A·N^(−α) + B·D^(−β)                       （经典项，B1 主拟合）
L(N,D,Q,p) = L(N,D) + γ·(1−Q) + λ·[f(p) − f(p0)]           （加性质量/配比修正）
```

N、D 单位统一为十亿（`N_params_B`、`D_tokens_B`），系数附带单位元数据；成本计算在 Q3 换算回实际参数/Token 数。

## 2. 估计顺序与数据角色

1. **经典项**：B1 Pythia 真实训练日志（1,176 行，8 规模 × 147 个 D 水平）多起点有界非线性最小二乘（正参数）。
2. **γ**：固定经典参数，在质量补充集 B6（半合成，主集）上对残差拟合 `γ(1−Q)`；B7 为替代情景，B8（含外推）单独报告。
3. **λ**：无同时含 Q 与 p 的联合观测，**不可辨识**；仅作为透明情景网格，`f(p)` 取自 Q1-A 预测器，`p=p0` 时该项恒为 0。

## 3. 结果

### 3.1 经典参数（B1）

| 参数 | 值 |
|---|---:|
| E | 1.6898 |
| A | 0.3540 |
| α | 0.3400 |
| B | 1.2403 |
| β | 0.2799 |
| 全样本 RMSE | 0.000146 |

无参数命中边界；偏导与有限差分相对误差 <1e-9（`scaling_parameters.json`）。

- B1 主拟合 RMSE=1.46e-4，与 CSV 中 `val_loss` 的 4 位小数显示精度同量级，因此留出 R²≈1 **不构成泛化证据**，只说明 B1 序列高度符合幂律形式。

### 3.2 验证

| 来源 | 划分 | n | RMSE | R² |
|---|---|---:|---:|---:|
| B1 | 全量拟合 | 1,176 | 0.00015 | 1.0000 |
| B1 | 留一规模（8 折，每折 147） | 147 | 0.00010–0.00022 | 1.0000 |
| B1 | 轨迹前/后段（前 70% 拟合） | 352 | 0.00012 | 1.0000 |

- B1 近乎完美拟合说明该日志高度符合幂律形式，不代表跨来源泛化；B2 为半合成且标定不同，R² 为负，如实保留。
- B1 与 B4/B5 无完全重复点（P0 审计 `_overlap_B1`=0）。

### 3.3 γ（质量修正）

| 数据集 | γ | 截距 | R²(残差) | 不含 Q 的 RMSE |
|---|---:|---:|---:|---:|
| **B6（主）** | **+0.3633** | 0（基线情景） | 0.694 | 0.217 |
| B6（允许来源截距） | +0.3622 | +0.0007 | 0.694 | 0.217 |
| B7（替代） | +0.3634 | 0 | 0.669 | 0.207 |
| B8（大规模，含外推） | −2.09 | 0 | 0.931 | 1.183 |

- B6/B7 一致给出 γ≈0.363，与 B6 内“固定 (N,D) 下 Q 越高 Loss 越低”一致（域内相关 −0.92）。
- **B8 符号为负且并非单纯外推所致**：即使在 B1 实测范围内（456/1704 点），B8 的残差与 `1−Q` 相关也为 **−0.988**（B6 为 +0.856）。说明 B8 的 Q 坐标方向与 B6 相反（跨来源标定/坐标不一致），不能与 B6/B7 合并估计 γ；`gamma_estimates.json` 同时保存全样本与支持范围内的相关系数。**不采用 B8 估计 γ**，仅作跨来源不相容记录。
- Q 标度校准：最简假设“B6 的 `Q_score` 与 Q1 的 Q 同刻度”，标为**未验证假设**（`mixture_transfer_scenarios.json`）。

### 3.4 弹性与等效规模

- `ε_N<0`、`ε_D<0`、`ε_Q=−γQ/L<0`，其中 **L 取总预测 Loss**（按计划 §2.5 定义）；另存以经典项 L0 为分母的 `epsilon_N_classical_part`、`epsilon_D_classical_part` 仅作对照，避免两种分母混用。Q 提升 0.1 的收益 `ΔL_Q=0.0363`（加性模型中不随基线 Q 变）。
- 等效参数规模 `N_eq/N−1`：0.07B→+13%、0.4B→+26%、1B→+38%、2.8B→+59%、12B→+123%（均 finite）。数值随 N 增大，故不报告全局固定替代率。
- 详见 `elasticities.csv`、`quality_parameter_equivalence.csv`。

### 3.5 配比迁移情景

- `f(p0)` 等权评价 Loss = 5.3447（按 Q1 记录协议删参考域、不二次归一化；等于 `mean(intercept)`，测试已锁定）。
- λ 情景网格 [0, 0.5, 1.0, 2.0]，默认 0；Q3-A 固定 p=p0 时该项为 0。

## 4. 验证与对照

- B1 留一规模/轨迹切分为真实留出（无行重叠）；B2/B4/B5 使用冻结的 B1 参数评估，不重新拟合。
- 经典项与加性修正消融：γ 模型中"不含 Q"的 RMSE 0.217 → 含 Q 0.076（B6）。
- 偏导数值与有限差分一致；等效规模对无解/仅增 N 不可达情形有显式状态。
- `tests/test_baseline_a.py` 覆盖参数拟合质量、偏导一致性、等效规模有解/无解。

## 5. 局限与未满足项

1. λ 不可辨识，仅情景参数；未声称已由数据估计。
2. B1 主拟合近完美，跨族/文献/B2 误差明显更大，模型不宜外推到 B1 范围外（B8 已显示符号反转）。
3. γ 来自半合成 B6/B7，且依赖“Q 同刻度”假设；无真实联合 Q–Loss 观测可交叉验证。
4. 未做 B9/B10 大模型外推情景的完整解释（属计划 §2.6 要求的一部分，本轮以 B8 记录边界问题代替）。
5. B3 插值轨迹未单独运行（计划要求 B2/B3 至少其一；已用 B2）。
6. 未输出参数/预测区间（计划 §2.6 要求的经验分组 bootstrap 区间与情景包络）；本轮仅报告点估计与误差，列为未满足项。
7. B9/B10 大模型外推情景未实现；B8 的跨来源 Q 坐标不相容已作为边界证据记录。
