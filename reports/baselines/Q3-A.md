## 1. 问题与约束

固定 `Q=Q0=0.586`、`p=p0`，最小化 `L0(N,D)+γ(1−Q0)`：

```
D·[(6 + η·ℓ)·N + max(g(Q)−g(Q0), 0)] ≤ C,   η = 2×10⁻⁴
```

固定 Q 时 `[g(Q)−g(Q0)]_+ = 0`，预算紧约束，`D = C/[(6+ηℓ)N]`。搜索 log N（10⁻⁴–10⁵ 十亿，网格 + 有界细化），并用加性幂律解析解核对：

```
N* = [ (αA)/(βB) · (C/a)^β ]^(1/(α+β)),  D* = C/(aN*),  a = 6 + ηℓ
```

## 2. 情景

- 预算：10¹⁹、10²²、10²⁴ FLOPs；另加 log C 连续网格（10¹⁸–10²⁵，21 点）观察路径。
- 上下文：C7 的 2048 / 4096 / 8192 / 32768 / 131072，`η=2×10⁻⁴`。
- 成本形式（题给）：指数 γ=10⁷,λ=6；幂 γ=5×10⁹,λ=4；对数 γ=2×10⁹,λ=10。

### 3.2 解析核对与约束

- 数值解与解析解 Loss 最大相对差 **2.2×10⁻¹⁶**，N 最大相对差同量级；无搜索边界命中。
- 成本约束残差 |total−C|/C < 10⁻⁹，未使用份额为 0（紧约束）。
- 份额公式 `训练=6/a`、`注意力=ηℓ/a`，和为 1；`ℓ_crit=6/η=30000`，ℓ=32768/131072 时注意力份额 >50%。
- 15 个情景中 7 个落在 B1 实测范围外（主要为 10²⁴ 预算），已标记 `extrapolation=True`。

### 3.3 预算路径（`budget_paths.csv`）

- 固定 ℓ 时 `N* ∝ C^(β/(α+β)) = C^0.4516`；N*、D*、L 随 log C 连续平滑变化。
- ℓ 越大，注意力成本越高 → 最优 N、D 越小、预测 Loss 越高（同预算）。

### 3.4 成本形式与结构转移

- 固定 Q=Q0 时三种 g(Q) 的额外成本项均为 0（`cost_check.csv`，列出 g(Q0) 仅作透明记录），**本问不区分成本形式**。
- `transition_candidates.csv`：未检出结构转移。固定 ℓ 下训练/注意力份额之比恒定（不随 C 变），且 Q、p 固定，按计划 §3.4 不硬造领域/质量转移。
- 这是 Q3-A 的设计限制：它只回答“固定质量与配比时预算如何在 N、D 间分配”。

## 4. 验证与对照

- 三档预算、三类成本、全部 C7 长度情景均有结果（成本形式相应说明为不激活）。
- 解析案例与数值结果一致；网格加密（21 点连续路径）未产生伪转移。
- `tests/test_baseline_a.py` 校验成本不超预算、份额和为 1、解析-数值一致、外推标记一致。

## 5. 局限与未满足项

1. Q、p 固定，不探索质量投入或配比调整；质量成本项 `g(Q)−g(Q0)` 未被激活。
2. 10²⁴ 预算的解超出 B1 支持范围，属外推，不能作为已观测结论。
3. 未做参数不确定性/迁移强度敏感性（计划 §3.5 要求之一），列为待办；Q3-B/C 才覆盖质量与配比联合优化。
4. “上下文能力情景”按 C7 长度取值，未绑定具体架构。
