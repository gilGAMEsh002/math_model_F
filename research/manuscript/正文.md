# 算力约束下提升大语言模型能力的资源配置建模

> 工作稿（research/storyline，基线提交 9602259）。所有数字可追溯到 `research/runs/<run_id>/`。
> A6–A11 结果标注为探索性外部复核；A12–A15 仅作估算表一致性诊断；B8 为半合成/外推。

## 摘要

本文研究算力约束下提升大语言模型能力的数据资源配置。我们在固定数据切分与统一评价目标下，实现并复核了三条可解释基线（等权质量＋岭回归、二次混料＋有效数据量、熵权＋随机森林），并在独立研究环境中对修复后结果做统一口径对比。

主要发现：三条路线的经典标度律与求解器在退化极限下一致（最优解相对差约 1e-7），差异来自来源质量与配比通道。第一问中，同一候选集、同一 13 域等权评价下配比预测的排序能力存在稳定差异，但预测误差与决策质量并不等价：某条路线在 1B 尺度上预测误差更小、top-1 选方后悔值却高于随机期望。第二问显示，单一来源加性偏移解释了主要的预测改进（相对 M0 的 SSE 下降约 60%；完整嵌套模型约 90%。在嵌套总降幅中偏移约占 66%，该比例是固定加入顺序下的描述分解，不是独立因果贡献），而质量项在半合成来源族内显著（γ≈0.362，95% 区间不含 0）、在 B8（半合成/外推）被非负约束压到零边界，跨来源不存在统一正质量系数。第三问表明，来源加性偏移不改变同一可行域内的最优资源分配；排除质量参数族后，各预算与上下文情景的策略状态一致（相对变化不超过 0.9%），只有质量通道参数会改变投入方向，而该参数不可辨识。第四问的损失—能力桥接误差较大，前沿预测仅作情景外推。

关键词：数据价值；来源校准；质量收益辨识；算力约束资源配置；可复现基线

## 第 1 章 问题重述、数据与共同口径

### 1.1 问题重述与成本模型
在总计算预算 C 约束下配置参数规模 N、训练 Token 数 D、数据质量 Q 与领域配比 p，使验证损失最小。成本采用题给形式：D·[(6+ηℓ)N + max(g(Q)−g(Q₀), 0)] ≤ C，其中 η = 2×10⁻⁴。
质量成本函数为题给三种形状：指数型 10⁷·e^(6Q)、幂函数型 5×10⁹·Q⁴、对数型 2×10⁹·ln(1+10Q)。上下文长度 ℓ 取 C7 的 2048/4096/8192/32768/131072，临界值 ℓ_crit = 6/η = 30000。

### 1.2 数据图谱与性质
附件 A（质量与配比）、B（标度律）、C（评测与元数据）。每条数据标注来源性质（真实/半合成/插值/估算/子集）。质量样本 A1–A3 全量去重后 261,086 条；配比实验 A4/A5（训练）与 A6–A11（检验）、A12–A15（外推估算）。

### 1.3 三条基线与固定版本
A：22 维等权质量＋岭回归配比；B：二次混料＋有效数据量 D Q^κ h(p)；C：熵权质量＋随机森林配比与双通道标度律。冻结提交 A `c8b97cf4`、B `e498b2c6`、C `cf765761`。研究阶段通过适配器调用各自实现，不改写上游。

## 第 2 章 问题一：质量评分的不一致与配比的实际预测价值

### 2.1 目标
将异构质量信号合成为可比较的 Q，处理指标冲突，并检验 17 域配比对 13 个验证域损失的实际预测价值。

### 2.2 模型与假设
- A：22 维等权，语义分组（7 组）后最弱组用于冲突消解。
- C：熵权评分（与等权对照）＋冲突阈值＋短板消解。
- B：组内均值、组间几何均值与短板，使用同源重建样本（A1=50,412≠51,230）——本稿作为缺项/不同样本，不并入统一质量对比。
假设：质量方向与适宜区间为可复核的建模约定；冲突只表示不一致，不代表某一指标错误。

### 2.3 求解
归一化参数在参考集 A1 上冻结后应用；配比→损失用岭回归/二次混料/随机森林，超参在 A4/A5 内部交叉验证选择；C 的森林预测器在研究环境中重建为可执行对象（对拍 max abs diff 1.78e-15）。

## 第 3 章 问题二：来源校准与质量收益的区别及辨识边界

### 3.1 目标
区分“经典规模效应”“来源校准”“质量机制”，并在可识别范围内给出各来源误差与不确定性。

### 3.2 模型
加性质量模型：L = L₀ + δ + γ(1−Q)，其中 L₀ = E + A·n^(−α) + B·d^(−β)，n = N/10⁹，d = D/10⁹。
有效数据量/双通道形式：L = E + A·n^(−α) + B·[d·Q^κ·h(p)]^(−β)。

### 3.3 求解与协议
固定 B1 拟合的经典参数；嵌套顺序 M0（经典）→ M1（+来源偏移 δ）→ M2（+δ+γ≥0）→ M3（无约束诊断）；各来源使用同一样本与同一协议；对 γ 做 2,000 次行 bootstrap 区间；重拟合与固定模型的结果分列。

### 3.4 结果
- 三线经典项与退化最优一致（相对差约 1.4e-7）。
- 来源偏移：在 B1∪B6 的嵌套 SSE 分解中（样本 B1∪B6, n=1536），相对 M0 的 SSE 下降：加 δ 后 59.98%、加 κ 后 79.87%、加 ρ 后 90.34%；固定加入顺序 M0→δ→κ→ρ 下，占嵌套总降幅的比例分别为 δ 66.39%、κ 22.02%、ρ 11.59%（描述分解，非因果贡献）；逐来源固定→重拟合误差显著下降（B2 1.243→0.011、B4 0.293→0.088、B5 0.198→0.132）。δ 在代数上等于 M1 下残差均值，仅作核验。
- 质量项：B6 γ=0.362 [0.337,0.389]、B7 γ=0.362 [0.336,0.386]（区间不含 0）；B8（半合成/外推）γ 在非负约束下压到零边界且零改善。δ 与 γ 在各来源内部可分离（设计条件数≈3.9–4.2）。

[[FIG:r2a_regret.png|图 F3：点选方 vs 集成均值 vs 均值+惩罚 vs 随机期望（真实 top-1 后悔值）。]]

### 3.5 三类可分性（分别表述）
1. 来源内部参数可辨识：是（δ、γ 可分离）。
2. 共同质量系数是否获跨来源支持：否（B6/B7 显著、B8 零边界，无统一正系数）。
3. 真实训练收益是否被识别：否（缺真实联合质量—收益观测；B6/B7 为半合成）。

### 3.6 结论（直接回答）
来源校准与质量收益是两件事：先做来源兼容，才谈质量机制；在现有数据上质量收益不可辨识，其显著性只成立于半合成族内部。

## 第 4 章 问题三：条件化资源配置、稳定区域与策略分歧

### 4.1 目标
在算力约束下给出可执行的资源配置建议，并标明建议的适用条件与分歧区域。

### 4.2 模型与求解
固定质量与配比的资源分配：预算紧约束消去 D = C/[(6+ηℓ)N]，对 log N 搜索；联合质量与配比按 C 的 M1 模型在可信区域内枚举搜索。

### 4.3 一致建议（条件化）
- 固定 Q=Q_0,p=p_0：A 的 15 情景数值与解析一致（相对差 2e-16）；三线在关闭质量/配比通道时最优解一致（`max|ΔN|/N`≈1e-7）。
- 典型建议（条件：ℓ、成本形状、可行域）：预算越高，单位参数配比越偏向数据；上下文越长，训练与注意力成本份额越大（C_ attn/C_ train=ηℓ/6）。

### 4.4 稳定区域与分歧区域
- 稳定区域：来源加性偏移 δ 不改变 argmin(N,D,Q)（解析，且数值确认 dL 恒为 0.168237）；排除质量参数族后，所有预算(1e19/1e22/1e24)×上下文(2048/8192) 情景策略状态一致，`max|ΔN|/N ≤ 0.9%`；规模参数 α/β 的 bootstrap 区间不改变 regime。
- 分歧区域：只有质量通道参数 κ 改变投入方向（κ=0 时 Q 落于下界；κ 取上/下界时 Q 状态改变），而 κ 跨来源不可辨识。
- 依赖假设：来源偏移为加性常数；单模型 C 与题给三种成本形状；可行域与可信区域固定。

[[FIG:figures/F8_score_alignment.png|图 F8：A/C 文本评分对齐与单调映射（A1，n=51230）。]]

### 4.5 区间标注
情景包络（对预算/上下文/成本形状/参数情景取遍）与统计置信区间（如有）分别标注，不混称；不伪造精确最优建议。

### 4.6 结论（直接回答）
给出条件化配置建议：在固定质量与配比下按解析/数值一致解分配 N,D；当且仅当质量通道被识别时才改变投入方向。预测水平的改善（来源偏移）不足以支持不同的资源建议。

## 第 5 章 问题四：损失收益能否可靠映射为能力与前沿

### 5.1 目标与方法
将前三问的损失收益折算为能力与前沿，需经 Loss–Benchmark 桥接或直接能力回归。

### 5.2 实际采用路径（与代码一致）
主预测使用直接能力回归：S ~ b_N·log N + b_C·log C + r·t + 类型（0.9 分位前沿）。桥接 S_k = a_k − b_k·L 按可比性分层单独拟合，作为独立诊断，其留一误差未进入预测区间。预测式为
S(t) = S₀ + (b_N·w_N + b_C·w_D)·g·(t−t₀) + r·(t−t₀)，
时间项只计一次（与代码一致）。

### 5.3 结果
桥接：高可比 7 点 R^2≈0.158、中可比 68 点 ≈0.252（说明损失→能力非单值）；前沿：增长率取自 0.9 分位回归与全样本 OLS 的中位数（并保留分位回归区间作为情景）；12/24 个月三情景预测及区间见 `q4_frontier_forecasts.csv`，样本内得分上限约 52 分，24 个月预测越界，属外推。

### 5.4 检验与口径统一（修订记录）
- 点估计总体：开源（宽松=有许可证）子集的 0.9 分位；原 bootstrap 区间重采样总体为全体匹配模型，二者总体不一致。处理：不保留该统计区间，正文与摘要均不报告其置信区间/覆盖率，只报告情景包络（见 `第四问修订记录.md`）。
- 增长率、回测字段与正文已对齐；删除“预测区间已计入桥接误差”的表述；不把 LOO RMSE 机械加到区间，也不报告覆盖率。

### 5.5 结论（直接回答）
在当前数据上，损失收益不能可靠映射为可精确声称的能力前沿；桥接弱、外推越界，只支持情景化的趋势判断。

## 第 6 章 结论、贡献与边界

贡献：把“数据价值”分解为可比性（来源）与机制（质量/配比）两层；给出可复核的证据边界与负结果；给出条件化配置建议、稳定区域与分歧区域。

边界：质量收益的真实符号与幅度未被识别；κ、ρ 未通过可辨识性判定；λ 经训练内选择为零（该选择协议未支持正惩罚），不等同于不可辨识；10B/70B 为估算/外推；A6–A11 已被查看（探索性）；B 质量重建数据未纳入；第四问桥接弱；原 bootstrap 统计区间因总体不一致未采用，仅报告情景包络。
