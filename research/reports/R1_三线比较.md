## 3. 回答指定问题

### 3.1 哪些结果稳定，哪些依赖口径？

**稳定（可直接用于论文证据）**
- 三线经典项与退化最优解一致（§2，~1e-7）。
- 同一候选集 + 同一等权目标下的 **Q1 排序**：1M 上 C ≫ B > A；60M 上 C Spearman 最高；这三个集合是真实检验集。
- “预测误差与决策质量不等价”：B 在 1B 上 RMSE/Spearman 优于 A，但 top-1 后悔值 **0.333** 等于该候选集真实 Loss 极差（随机期望 0.114 的 ~2.9 倍）；A 在 1M/60M 也是低误差、高后悔。
- A 的固定质量/配比 Q3 基准（15 情景，数值-解析 2e-16）。

**依赖口径（必须标注后再比较）**
- 跨尺度绝对 RMSE/R²：不同模型规模，无意义；只能用 Spearman/regret。
- Q 坐标：C 的熵权/proxy 与 A 的 22 维等权不可直接排名；B 的质量用**同源重建集**（与题面 A1 不同样本），**不进入统一质量消融**。
- 10B/70B：估算/外推，非真实泛化证据；三线 Spearman 全负说明模型与该估计表不相容，不能断言真实规律反转。
- C 的 `best_entropy_proxyQ` 是其内部选取的变体；A/B/C 的 Q1 模型类不同，属**端到端比较**而非算法消融。

### 3.2 哪些模块适合保留/降级/舍弃？

- **保留**：A 的单位与坐标纪律、审计与解析校验；C 的 Q1 森林（同尺度与跨尺度排序最强，但需持久化预测器）；B 的二次混料（60M/1B 排序稳健，作为 C 的机制对照）；C 的成本/约束审计与候选枚举框架（去掉区域外顶点后）。
- **降级**：A 的岭回归（Q1 最弱，保留为最低参照）；C 的逐目标森林（事后调参，仅作探索）；所有“按各线自报最低 Loss 排名”的做法。
- **舍弃/不采用**：C 的 `lp_vertex_box` 顶点推荐（可信域外，已从主表移除）；B 的 1B top-1 选方（后悔值劣于随机）；跨线绝对 Loss 直接排名。

### 3.3 当前最值得进一步解释的矛盾

**同一候选集上的排序质量不能跨尺度迁移，且后悔值不随 Spearman 单调。**
- 1M：C Spearman 0.923、regret 0；到 1B：C Spearman 0.650、regret 0.070；到 10B/70B 全变负。
- B 在 1B 上 Spearman 0.478（优于 A 的 0.368），regret 却最差（0.333）；A 反之。
- 三线在 10B/70B 选了同一候选（regret 完全相同）。

这不是实现错误（Layer B 已证明三线在共同模型下自洽），而是**代理目标（RMSE/排序）与实际决策收益（regret）之间的失配**，且随规模外推恶化。它是本阶段最值得作为论文主线来解释的对象。

## 4. 论文主线候选（至多两个，均未定稿）

> 以下为**待检验命题**，不是选择结果；必须通过 §5 的最小辨别实验后才可写入主线。

### 候选甲：数据价值的“跨尺度可决策性”
- 已有证据：1M 上 C 的 regret=0；1B 上 C regret 0.070 而 B 0.333；10B/70B 全负（§1）。
- 关键缺口：缺少**固定上游、逐通道**的后悔值分解（经典项 / 质量通道 / 配比通道）。
- 最小辨别实验（R2a）：在 60M、1B 同候选集上，固定评价目标与候选池，分别只用 (i) 经典项 (ii) 经典+质量 (iii) 经典+配比，报告 top-1/top-5 后悔值与随机期望的差及其分组 bootstrap 区间。
- 支持条件：至少一个通道使 regret 在 ≥2 个尺度上稳定低于随机期望（区间不跨 0）。
- 否定条件：所有通道 regret 与随机期望不可区分，或仅单尺度成立 → 记为“无可决策增益”。
- 可复用代码：`src/r1_compare.py`（候选对齐、regret/随机期望）、`src/adapters.py`、A/B/C 各自的预测器。

### 候选乙：来源兼容优先于机制识别（质量坐标校准）
- 已有证据：A 的 γ 在 B6/B7 为正、B8 为负；B 用同源重建集；C 用 6 域 entropy 且有效指标数 8.16/22（`decisions.md`、旧分析报告）。
- 关键缺口：三线质量坐标不可比；B 的质量重建数据为 LFS 指针未 pull。
- 最小辨别实验（R2b）：在**同一质量样本与同一预处理**下重算三线的质量机制（先 A vs C；B 需先 `git lfs pull`），比较质量项符号/幅度与 CI。
- 支持条件：共同坐标下质量项符号一致且 CI 不含 0。
- 否定条件：符号仍冲突或 CI 跨 0 → 记“质量机制不可辨识”，主线退回候选甲或更简模型。
- 可复用代码：A 的 `src/common/quality.py`、C 的 `src/baselines/Q1-C/quality.py`、C 预处理（line-c 自带）。
