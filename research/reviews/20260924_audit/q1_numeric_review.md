# Q1 指标与候选匹配轻量复核

审查对象：`research/src/r1_compare.py` 的 `load_a/load_b/load_c`、`layer_a_q1`、`_metrics`；R1 输出 `research/reports/r1_q1_metrics.csv`、`r1_q1_set_identity.csv`，以及冻结上游的 Q1 预测/模型文件。原始 A4–A11 附件只读。本复核检查报告里的 Q1 描述性数字，不重训模型。

## 结论

**Q1 指标实现与报告数字相符；1B 的 B 线确实选中了本候选池真实等权 Loss 最差的一项。** 当前有力结论限于 A6–A11 对应的三个有限候选集。**C 的优势不能归因于熵权或质量评分**：R1 主列 `forest_none` 明确不含质量特征。它支持的是 C 这套配比预测流程在这些候选池上的端到端表现。

## 核对依据

1. **行索引及真实目标对齐。** 原始 A6/A7（1M，256 行）、A8/A9（60M，256 行）、A10/A11（1B，64 行）的 mixture 与 loss 表各自 `index` 顺序一致且唯一。A/C 落盘预测所覆盖的 ID 集与原始 mixture ID 完全相同；按 ID 重排后，A 与 C 的全部 13 个 `y_true` 对原始 Loss 最大绝对误差均为 0。B 复算直接读取其上游的 mixture/loss 文件；六个文件与仓库只读原始附件的 SHA256 逐一相同，且 mixture/loss ID 顺序相同。`r1_q1_set_identity.csv` 又核验三线同 ID 的 `y_true`，三个真实集合最大差均为 0。因此这不是仅凭行数相等推断候选相同。
2. **13 域等权目标。** `layer_a_q1` 设 `v=ones(13)/13`，`_metrics` 对每个候选计算 `y=Y@v` 与 `yh=Yhat@v`。A 的 `pred_`/`actual_` 字段、C 的 `row_index × target` 长表和 B 的 13 输出系数均按域名重排到共同域序；B 的系数目标顺序与上游 `LOSS_DOMAINS` 一致。它先把 13 域 Loss 做算术平均，再在候选间算 RMSE、Spearman 和选方 regret；并非先对各域 RMSE 求平均。
3. **指标定义正确。** Top-1 为 `argmin(yhat)` 候选的真实综合 Loss 减去池内真实最小值；随机期望 regret 为均匀随机抽取一个候选时的期望，即 `mean(y)-min(y)`。这些定义与 B 原始 `q1_mixture.py` 的 `regret()` 采用同一目标和口径。交叉复算 `layer_a_q1()` 与落盘指标相同（表中精度差来自展示位数）。

## 1B 选方复算

原始 A10/A11 对齐的 64 个候选，13 域等权真实 Loss 范围为 **2.111309–2.444240**，随机期望 regret 为 **0.114261**。真实最优候选 ID 为 **45**。三线预测最优项如下：

| 线 | 预测选中 ID | 该项真实等权 Loss | Top-1 regret |
|---|---:|---:|---:|
| A | 17 | 2.226913 | 0.115603 |
| B | 36 | **2.444240（池内最大）** | **0.332931** |
| C (`forest_none`) | 29 | 2.180875 | 0.069566 |

B 的 0.332931 等于候选池真实 Loss 极差 `2.444240−2.111309`，是随机期望 regret 的约 **2.91 倍**；所以“B 在该 1B 候选池选到最差项，且 regret 高于随机期望”是准确的描述性陈述。它只证明该模型在这 64 项上的 top-1 失手，不证明 B 在一般 1B 配方问题中必然比随机更差。

## C 优势的归因边界

R1 的 C 主列来源是 C 的 `forest_none`。上游 `Q1-C/mixture.py` 将 `none` 定义为不加入质量特征；森林模型/超参数选择在 A4/A5 训练内交叉验证进行。故主表中 C 在 1M/60M/1B 的较好排序或后悔值**不能被解释为熵权评分带来的收益**。

单列的 `C_posthoc=best_entropy_proxyQ` 才加入 entropy/proxy Q；它与主列非常接近：RMSE 分别为 1M `.11750` 对 `.11874`、60M `1.50760` 对 `1.51155`、1B `2.93128` 对 `2.92856`；1B Spearman `.64995` 低于 `forest_none` 的 `.65559`，top-1 regret 二者相同。该变体在最终检验结果被查看后列入对照，不能当作盲测优势或干净的质量特征消融。即使仅看这一变体，也没有熵权使选方改善的稳定证据。

## 可安全用于论文的表述

可以写：在同一批真实 A6–A11 候选、同一 13 域等权 Loss 上，三条**完整基线流程**的描述性排序和选方表现不同；B 在 1B 的单次 top-1 选中池内最差项，说明回归误差/排序指标不保证单次选方可靠。需保留“有限候选池、探索性外部复核”的限定。

不宜写：C 因熵权质量评分而最好；B 的一般 1B 决策一定劣于随机；上述单个池结果足以证明各路线总体决策能力有统计显著差异。当前代码与 CSV 给出精确的池内描述量，没有对候选池抽样不确定性做统计推断。
