# 第四问与 PDF 独立核查

日期：2026-09-24。审查版本：研究仓库 `5efe63dc66ad5c12734c4a9beb8576e24b06bf96`；B 线上游为 `upstream.lock.json` 固定工作树。未修改论文、上游代码或原始附件。复算脚本 `audit_q4.py`，输出 `q4_type_sensitivity.csv`、`q4_audit_summary.json`。

## 1. 高优先级：正文预测式与实际代码不一致

- 正文 `research/manuscript/正文.md:129–131` 声称实际主预测为 `logN + logC + t + 类型`，写出 `(b_N w_N + b_C w_D)gΔt + rΔt`，并强调“与代码一致”。
- 实际 `../F题-upstream/line-b/code/q4_frontier.py:322–329` 选用 M1，即 `S=a+b_N log10 N+r t+c chat`；`467–486` 预测只使用 `b_N w_N gΔt+rΔt`。保存表 `q4_capability_models.csv` 的 M1 系数是 `b_N=14.3341, r=12.8455`，不是 M3 的 `b_N=8.17847,b_C=5.90627,r=12.8237`。
- 因此当前文字无法复现保存的预测结果。即便改用含 `logC` 的 M3，沿算力路径 `d log C/dt=g`，其贡献也应为 `b_C gΔt`；乘 `w_D` 只有在该系数属于 `logD` 时才成立。
- 0.9 分位只用于起点 S0；能力斜率是全样本 OLS，不能将它表述为已经拟合的条件 0.9 分位能力模型。C4 的 `logC~t` 才是实际做的分位数回归。

影响：第四问所述模型与预测结果之间的可复现性断裂。最小修正是准确报告实际 M1 及其情景假设；若要用 M3，必须重新生成预测与验证，不能只改公式。

## 2. 高优先级：类型编码不符合“预训练 vs chat/finetuned”定义

`q4_frontier.py:231–235` 只检索 Type 中是否包含 `chat`，把其余全部称为 pretrained。`370` 的“≥7B 预训练固定组成”同样使用 `~is_chat`。

原始 C1 的 4,576 行中：

| 类型 | 行数 | 原编码 |
|---|---:|---|
| pretrained | 275 | 非 chat |
| continuously pretrained | 58 | 非 chat |
| fine-tuned on domain-specific datasets | 1,785 | 非 chat，被汇报为 pretrained |
| base merges and moerges | 1,724 | 非 chat，被汇报为 pretrained |
| chat | 718 | chat |
| multimodal / other | 16 | 非 chat |

这不只是用词错误：该编码进入能力回归、时间项、贡献分解及前沿预测。独立复算原始 C1 的 4,561 条有效样本，复现原预测；固定样本、S0、增长率、其余回归协议，只更换类型编码得到：

| 编码 | 时间系数（分/年） | 增长延续 24 月预测 | 放缓 24 月预测 |
|---|---:|---:|---:|
| 原 chat-only | 12.8455 | 71.5155 | 67.4508 |
| chat 或 fine-tuned 合为后训练类（敏感性） | 11.7649 | 69.3645 | 65.2946 |
| 保留原 Type 的全部分类效应（敏感性） | 10.7198 | 66.7035 | 62.9191 |

这证明类型处理会实质影响预测，差异约 2.15–4.81 分。后两行是诊断，不是已验证的替代预测；需要明确 merged、持续预训练、未知类型的处理，并对修订模型重做时间验证。

## 3. 高优先级：目前回测未验证未来前沿目标

- `q4_frontier.py:525–540` 对未来 90 天逐模型得分预测，使用未来模型已知的 N、类型；结果记录逐模型 RMSE/MAE 和均值。
- 主预测的目标则是未来开放模型能力前沿，其规模来自假设的最优路径，起点为宽松开源子集的全时间段 p90。当前回测没有对这个“前沿＋规模路径＋筛选总体”预测器滚动复算，不能据此声称 12/24 月前沿已通过回测。
- `S0=37.6950` 取全部历史开放子集 p90，不是截止日条件前沿。作为诊断，同一许可口径最近季度 p90 为 `40.4250`，相差 2.73 分。两者都不是自动正确的未来起点，但正文必须说明前沿的时间窗口。
- 主模型时间窗口仅 2024-06-08 至 2025-03-13；时间系数代表这一窗口中的条件相关性，不能自动称为非规模技术进步的因果效应。类型错分进一步削弱该解释。

影响：现在只能报告具体假设下的情景外推，不能从该回测得出前沿预测可靠的结论。

## 5. 中优先级：修订记录仍有口径残留

- 正文 134 行仍说“预测及区间见 q4_frontier_forecasts.csv”；这个 CSV 的 `S_ci_lo/S_ci_hi` 正是已宣布弃用的 bootstrap 区间。应提供只含情景点值/包络的最终表，明确废弃列不可使用。
- 正文说分位回归的增长率置信区间“保留作情景”，但代码 `476` 实际仅使用 `g,0.5g,0.1g`；`gq_lo/gq_hi` 只打印，没有进入预测情景。
- bootstrap 实际从全部具有日期、参数、得分的 `dd` 重采样，并非仅“全部匹配模型”；总体不一致的问题判断正确，但修订记录对总体的名称仍不准确。
- 预测超过历史样本最大分约 52，只说明超出观测响应范围，不构成违反 0–100 分上界的数学错误，也不足以单独否定预测。真正问题是预测模型、目标、分层和验证没有统一。
- 桥接 R² 低支持“当前线性桥接解释力有限”，不能据此证明 Loss→能力本质上非单值。高可比层仅 7 点且能力取值范围窄，应报告留一误差和与简单均值预测器的比较。
