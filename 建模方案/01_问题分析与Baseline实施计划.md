## 1. 第一问：质量评价、冲突消解与领域配比

### 1.1 问题分析

本问需要回答三个问题：质量指标如何合成一个可比较的 Q；同一文本上的指标不一致如何解释与处理；17 域配比如何影响 13 个验证领域的 Loss。

质量分是一个依赖任务目标的代理量，不是先验真值。不能用“公式复杂”代替原文核验，也不能用高相关性证明因果关系。

### 1.2 共同预处理

建立 `quality_metric_dictionary.csv`，覆盖全部 22 个字段，记录原始语义、标量化方式、方向/效用变换、缺失处理、依据和待核验事项。

| 字段类型 | baseline 处理 |
|---|---|
| `fineweb_edu` | 取单元素，按固定参考尺度归一化 |
| `modernbert_*` 六分类 logits | baseline 用 `argmax/5`；softmax 等级期望作为敏感性对照 |
| `fluency_en` | 取流畅类 softmax 概率 |
| `ad_en` | 官方顺序为 `[has_ad,no_ad]`，取无广告类概率，已是正向 |
| `qurater` | 四个子维度各自标准化，再平均；不当成分类 logits 做 softmax |
| `dsir_*` | 核验分数定义与长度效应，再固定方向和稳健变换 |
| 重复率等明确负向指标 | 稳健归一化后作补转换 |
| 词数、词长、数字比例等 | 用有依据的饱和/适宜区间效用，不机械规定单调方向 |

只有确认语义后才冻结变换。异常值截尾界限、缺失填补和归一化参数使用预定参考集估计，保存并应用于其他集合；不对每个域分别做分位数变换后直接比较域级高低。

A1 中按域划分评分规则开发样本和人工核验样本，保留独立审核部分。扩展集用于冻结规则后的迁移检查；独立性检验使用去除 A1 重叠记录的部分，但全量评分与域级汇总仍须覆盖全部记录。

### 1.3 冲突的共同定义与处理

按指标语义预定义质量组，设各组分数为 z_ig。冲突强度采用易解释的范围差：

\[
c_i=\max_g z_{ig}-\min_g z_{ig}.
\]

`c_i > τ` 是初始冲突标签；τ 用开发样本分位数确定，并做多个阈值的敏感性分析。另输出“教育价值高、无广告分低”等具体冲突类型。

范围差只能发现不一致，不能证明某一指标错误。区分真实短板、领域特征造成的误判、测量器不可靠、相关指标重复计权。

简单消解规则使用算术平均与最弱质量组的凸组合：

\[
Q_i^{\rm resolved}=(1-\lambda)Q_i^{\rm base}+\lambda\min_g z_{ig},
\quad 0\le\lambda\le1.
\]

λ=0 是不处理冲突的消融；选择小规模预设网格并通过核验集比较，不直接规定最优值。该规则体现短板约束，不将“差异大”一概视为低质量。检查单指标改善时综合分不下降。

### 1.4 三个 baseline

| 编号 | 质量评价 | 配比预测 | 用途 |
|---|---|---|---|
| Q1-A：最简主基线 | 22 维等权平均；报告消解前后 Q | 16 个配比变量加截距的岭回归，逐验证域拟合 | 快速闭环、易解释 |
| Q1-B：短板与交互基线 | 组内平均，组间几何平均；零值使用固定小正数并做敏感性 | 二次混料回归＋岭惩罚 | 检查短板与领域搭配 |
| Q1-C：非线性对照 | 熵权评分＋共同冲突规则；与等权对照 | 随机森林，多输出或逐目标拟合 | 判断非线性是否带来可靠收益 |

熵权来自评分开发参考集，不能解释成因果重要性；高变异也可能意味着噪声。树模型在训练折内进行小规模调参，不依赖默认配置的偶然结果。

二次混料模型使用：

\[
\widehat L_k(p)=\sum_i a_{ki}p_i+\sum_{i<j}b_{kij}p_ip_j.
\]

不再同时加入造成冗余的完整常数与平方项；通过正则化和训练集交叉验证控制复杂度。组合系数仅表示相对该模型线性混合预测的偏离，跨域替代解释还需可行方向扰动。

固定评价目标：

\[
L_{\rm eval}(p)=\sum_{k=1}^{13}v_kL_k(p),\quad v_k\ge0,\quad\sum_kv_k=1.
\]

baseline 令 v 等权，同时保留各领域误差。不得使用随 p 改变的评价权重。没有直接 Loss 列的 4 个训练域仍保留为输入，不虚构其验证 Loss。

## 2. 第二问：跨维度融合与广义标度律

### 2.1 问题分析

B1 可以估计 N、D 与 Loss 的关系；B6–B8 提供质量相关的半合成变化；第一问提供质量和配比效应。三者不是同一联合实验，不能直接按行拼接，也不能假设它们的 Loss 和质量坐标天然相同。

先建立来源、验证集和质量坐标的可比性假设，再分阶段估计。对缺少联合观测的参数报告不可辨识性，不用数值优化器返回一个点值掩盖证据不足。

### 2.2 必做的经典对照

\[
L_0(N,D)=E+AN^{-\alpha}+BD^{-\beta}.
\]

以 B1 为主，用带正值/合理区间约束的非线性最小二乘，多起点拟合；保存边界命中和残差图。对加性幂律整体取 log 后做普通线性回归并不等价。

按规模或完整轨迹分组留出；D 方向可以另做前段训练、后段检验。固定步距检查点高度相关，不能随机拆行后将误差称为独立泛化误差。

### 2.3 三个广义 baseline

| 编号 | 模型 | 主要假设 |
|---|---|---|
| Q2-A：加性修正 | L=L0+γ(1−Q)+λΔf(p) | 质量/配比局部改善独立叠加 |
| Q2-B：有效数据量，优先作为主模型 | L=E+A N^(−α)+B[D Q^κ h(p)]^(−β) | 质量和配比改变 Token 利用效率 |
| Q2-C：双通道效率 | L=E+A[N Q^ρ]^(−α)+B[D Q^κ h(p)]^(−β) | 质量还影响参数利用效率 |

其中 Δf(p)=f(p)−f(p0)，h(p)>0 且 h(p0)=1。Q2-B 的一个简单候选是：

\[
h(p)=\exp\{-\omega[f(p)-f(p_0)]/s_f\},
\]

s_f 为第一问训练参考集上预测 Loss 的固定尺度，ω 为无量纲迁移强度。较低的预测 Loss 对应较高 h。该形式是可检验假设，不是已知规律。

### 2.4 跨源融合与估计顺序

1. 只使用第一问导出的结果与预测器，不重复读取 A 原始文件。
2. B1 拟合经典参数，先固定这些参数作为分阶段 baseline。
3. 选择 B6 为质量主集，B7/B8 做替代或扩展情景；相同实验点不能重复计权。
4. 定义第一问原始 Q 到模型 Q 的单调映射并保存。最简方案可以显式假设同尺度，但必须标为未验证假设，比较替代单调映射。
5. B1 缺少 Q 和 p 时，基准归一化属于约定，不代表其语料被实测为完美质量。对基准 Q 的替代取值做敏感性分析。
6. 在必要的来源偏移下估计 γ 或 κ；检查单独质量模型对半合成数据的拟合与真实主模型是否相容。
7. ω、λ 等跨源转换强度缺少共同实验时，不报告“已由 B1 精确估计”。给出包括零效应在内的小组预设情景，并将选择传入第三问。
8. 联合微调作为对照时，限制半合成集权重，分别展示真实和半合成残差，防止数量优势覆盖真实主拟合。
9. Q2-C 若 ρ、κ 高度相关或置信区间过宽，保留为未辨识对照，主结论退回 Q2-B。

### 2.5 边际收益、弹性与替代

统一输出偏导数和弹性：

\[
\varepsilon_x=\frac{\partial L}{\partial x}\frac{x}{L}.
\]

降低 Loss 的因素通常具有负弹性。另可报告相对于可约损失 L−E 的弹性，但不得与总 Loss 弹性混用。有限差分仅用于校验导数，不能把 ΔL/ΔN 直接叫作弹性。

对 Q2-B，令 X=D Q^κ h(p)，则：

\[
\varepsilon_N=-\alpha A N^{-\alpha}/L,\quad
\varepsilon_D=-\beta B X^{-\beta}/L,\quad
\varepsilon_Q=-\kappa\beta B X^{-\beta}/L.
\]

对于 Q+0.1≤1，定义质量改善收益：

\[
\Delta L_Q=L(N,D,Q,p)-L(N,D,Q+0.1,p).
\]

Q2-B 下，同等收益的参数规模为：

\[
N_{\rm eq}=\left[N^{-\alpha}-\Delta L_Q/A\right]^{-1/\alpha}.
\]

括号为正才有有限解；等于零需无限规模；小于零则仅增加 N 无法实现同等收益。报告 N_eq/N−1，同时报告基准 N、D、Q、p，不能给全局固定替代率。

等损失曲线的 dN/dQ=−L_Q/L_N 通常为负；“独立增加 N 来替代独立增加 Q”的增益匹配比 L_Q/L_N 则为正，二者勿混淆。

等算力比较使用 −L_x/C_x，并明确其他变量的固定方式；第三问再求实际联合最优。领域替代采用 p_i 增 δ、p_j 减 δ 的单纯形可行扰动，不能独立增加所有配比。

## 3. 第三问：算力约束下的资源联合优化

### 3.1 问题分析与共同约束

使用第二问选定模型，求解：

\[
\min_{N,D,Q,p}\widehat L(N,D,Q,p)
\]

\[
D\{(6+\eta\ell)N+[g(Q)-g(Q_0)]_+\}\le C,
\quad p_i\ge0,\quad\sum_i p_i=1,
\quad \eta=2\times10^{-4}.
\]

baseline 使用固定 Q0 和 p；联立 p 时必须解释 Q0 是否应随语料组成变化。只考虑质量提升、且损失对 Q 单调改善时，可限定 Q≥Q0；否则需说明下界设定。

若损失随 D 单调下降且无额外 D 上限，则预算紧约束，消去 D：

\[
D=\frac{C}{(6+\eta\ell)N+[g(Q)-g(Q_0)]_+}.
\]

实施前检查这些前提。若存在数据上限，令 D 取预算允许值与上限的较小者，报告预算剩余。

N、D 的数值搜索边界需给出依据；先在数据支持范围内求解，再单独报告外推扩展结果。边界命中可能是人为截断，不应立即解释成经济结构转移。

### 3.2 三个 baseline

| 编号 | 方法 | 具体步骤 |
|---|---|---|
| Q3-A：规模分配参照 | 固定 Q=Q0、p=p0，搜索 log N | 用约束求 D；包括上下文成本 |
| Q3-B：二维搜索主基线 | 固定第一问优选配比，搜索 log N 和 Q | 先粗网格后局部细化，每点精确计算成本 |
| Q3-C：配比候选联合优化 | 枚举第一问优质配比，每个候选运行 Q3-B；多起点 SLSQP 可选 | 仅在数据支持区域内细调 p，比较联合与固定配比 |

对 Q3-A，若 L=E+A N^(−α)+B_eff D^(−β)，令 a=6+ηℓ，解析参照为：

\[
N^*=\left[\frac{\alpha A}{\beta B_{\rm eff}}(C/a)^\beta\right]^{1/(\alpha+\beta)},
\qquad D^*=C/(aN^*).
\]

该式只用于满足前提的固定质量/配比、无额外边界案例，可核验数值搜索。不能直接推广到带质量成本的全部情景。

### 3.3 必做情景

预算：10^19、10^22、10^24 FLOPs；额外在 log C 上取网格观察连续变化。

| 成本形式 | 题给 g(Q) | 参数 |
|---|---|---|
| 指数型 | γ exp(λQ) | γ=10^7，λ=6 |
| 幂函数型 | γQ^λ | γ=5×10^9，λ=4 |
| 对数型 | γ ln(1+λQ) | γ=2×10^9，λ=10 |

主比较使用题给参数；如需区分“曲线形状”与“成本量级”的影响，另增加基准点成本/斜率校准对照，不替代题设实验。

题给对数型 g''(Q)<0，边际成本递减，并非趋近 Q=1 时发散的成本。应如实解释可能的边界解。

上下文依据 C7，按可行架构情景分别取值：

| ℓ | C_attn/C_train=ηℓ/6 |
|---:|---:|
| 2048 | 0.06827 |
| 4096 | 0.13653 |
| 8192 | 0.27307 |
| 32768 | 1.09227 |
| 131072 | 4.36907 |

解析临界值 ℓ_crit=6/η=30000。不可把 C7 中某架构支持的最大长度自动赋予其他架构。若 N 连续且无法对应具体架构，明确采用“上下文能力情景”，并补充有元数据对应的离散案例。

### 3.4 结构性转移的识别

预先定义以下事件，报告数值容差和稳定性：

1. Q* 从 Q0 边界进入内部，或达到上界。
2. p* 的支持集发生稳定变化，即领域占比跨越预设的小阈值。
3. 最优策略的预算弹性或份额曲线出现可复现的分段变化。

输出训练、质量和注意力成本份额，份额分母统一为总预算 C，另报告未使用份额。

只在三个离散预算点观察到差异不足以证明变点。需要局部加密、不同初值/网格、成本与参数扰动下复核。若连续平滑变化或未检出稳定转移，就报告未发现转移。

在本题算力代理下，固定 ℓ 时 C_attn/C_train 恒定，因此两者份额之比本身不会随预算产生结构转移。

若模型把配比效果完全表示为一个与 N、D、Q 无关的可分离 h(p)，且没有配比相关成本/供给约束，那么最优 p 可能对所有预算相同；此时不能硬造“领域转移”。

## 4. 第四问：技术演进、贡献分解与前沿预测

### 4.1 问题分析

首先统一“能力”“开放模型”“模型类型”和“时间”的口径，然后讨论规模与非规模变化。数据工程已在 Q、p 中解释的收益，不得在时间趋势中再次完整计入。

默认使用统计分解或动力学情景模型。仅加入时间项不构成因果识别；若没有可信识别设计，称为“控制观测规模后的非规模关联”，说明它还可能包含评测变化和遗漏因素。

### 4.2 数据与口径

1. 综合分以六项同口径得分等权平均为 baseline，缺任务不自动按剩余项平均冒充完整六维分数。
2. 核验 C1/C8 的原始、归一化和随机猜测校正分数，不将原始正确率乘 100 后直接替代排行榜分。
3. 明确开放权重与许可证允许研究复现的规则；无法确定者进入未知组，不自动视作关闭或开放。报告严格/宽松筛选敏感性。
4. 基础、持续预训练、chat/finetuned、合并、多模态等先分组；主分析至少区别 pretrained 与 chat/finetuned。
5. C4 提供算力、数据量和权重开放等字段，报告匹配规则、覆盖率、人工核验和未匹配记录。数据量单位不清楚时不能作为 Token 直接代入。
6. 主评测时间轴可以选提交日期；C4 发布日期保留为独立字段，补充敏感性对照，不静默混用。
7. C3 与 C1 的重叠记录去重。历史来源单列；不同年份不同评测口径不得无条件拼成同尺度增长曲线。
8. 预测起点 t0 取指定分析样本的有效截止日，保存实际日期。不能把系统当前日期当作数据截止日。

### 4.3 C8 逐任务分析

- 按目录选最新可解析记录，保留旧版本和损坏文件的审计清单。
- 至少对 BBH 子任务做宏平均，并以题量加权平均作对照；只聚合叶子任务，避免父子重复计数。
- 使用任务配置中的指标、版本和样本量，固定聚合规则。
- 分析模型类型/规模组在子任务上的差异；可用任务间离散度解释综合分掩盖的能力不均衡。
- 与 C1 匹配后检查聚合差异，区分版本差异、归一化差异和缺任务造成的偏差。

### 4.4 Loss–Benchmark 桥接

优先使用 C6，C5 作为重叠审计和对照。先画各任务散点与来源分层，再拟合：

\[
S_k=a_k-b_kL,\quad b_k\ge0,
\]

或：

\[
S_k=100\sigma(a_k-b_kL),\quad b_k\ge0.
\]

若任务的官方量表不在 [0,100]，先按其定义确定界限，不机械套用 sigmoid。高可比仅 7 条，复杂模型不适合；基础模型桥接不可自动用于所有微调模型。

高可比组作主锚点，中可比组做来源/模型族分层和敏感性分析；任意指定的可信度权重标为情景权重。留一模型/模型族验证，不将少量样本的漂亮拟合线当作强泛化证据。

### 4.5 三个 baseline

| 编号 | 方法 | 交付重点 |
|---|---|---|
| Q4-A：规模—时间回归 | S=a+bN log N+bD log D+r t+类型/族效应 | 统计贡献分解，简单透明 |
| Q4-B：效率增长动力学 | C_eff(t)=C(t)exp(κ(t−t0))，经 Q3 与桥接得到能力 | 完整串联前面三问 |
| Q4-C：高分位数前沿 | 对统一能力变换后的 S 拟合 0.90/0.95 分位数的规模和时间关系 | 直接预测操作性前沿 |

Q4-A 必须有含 C4 数据量的匹配子集分析；另用 log C 替代 log N、log D 做规模测度对照，报告样本选择差异。不要同时无约束加入 log N、log D、log C，因为 C≈6ND。

模型族、类型、时间和规模若缺乏组内变化，需简化模型并报告不可辨识性。分位数预测以接近前沿的条件分布为对象，不宣称估计严格上界或未来最大值。

Q4-B 的效率系数 κ 只表示未被显式质量/配比等变量覆盖的剩余效率趋势；如果数据不能分离这些通道，应分别运行替代情景，不将其收益机械相加。

### 4.6 贡献分解

在类型/族组成固定的口径下，Q4-A 可用：

\[
\Delta S_{\rm scale}=b_N\Delta\log N+b_D\Delta\log D,
\qquad \Delta S_{\rm non-scale}=r\Delta t.
\]

这分解的是模型预测变化，并非所有观测变化；另外报告组成变化和残差。先输出贡献量，再输出相对总预测变化的比例。总变化近零或贡献相反时，比例可能不稳定或超出 0–100%，不能强行截断。

非线性模型使用两个因素的顺序平均分解：分别按“先规模、后技术”和“先技术、后规模”计算，取各因素贡献平均，避免任意顺序决定结论。

### 4.7 预测与验收

在 t0 后 12/24 个月分别设置历史增长延续、算力增长放缓、算力近乎不变情景。情景增长率来自样本估计或明确假设，不能写成事实预测。

基于时间滚动切分回测，在每个历史截止点重新拟合；用分组 bootstrap/时间块重采样传播参数、桥接与趋势误差。模型选择和预测评估不能使用未来数据。

未来最大成绩还取决于参评模型数量。若不建模数量，使用“高分位数前沿”而非“未来一定出现的最高分”。

## 6. 最小有意义的验证

实施 agent 的测试聚焦会改变结论的错误，不为每个绘图函数堆积测试：

1. A 配比/Loss 连接一对一、列序一致、配比归一化正确。
2. logits 标签方向、指标变换、重复样本和评分范围正确。
3. N/D 单位换算与成本数量级正确，解析参照可复现。
4. 标度律偏导与有限差分一致，边界及无解替代条件正确处理。
5. 优化成本不超预算，配比可行，网格/初值变化不制造伪转移。
