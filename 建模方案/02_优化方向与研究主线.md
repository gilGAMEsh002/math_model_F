# 优化方向与研究主线

## 0. 从 baseline 证据出发

本文件在 [Baseline 实施计划](./01_问题分析与Baseline实施计划.md) 之后使用。目标是找到一个贯穿四问、可证伪且有实际意义的问题，避免把四问写成互不关联的算法展示。

所有故事标题均为候选研究问题，不是已获得的结论。每次优化要同时回答：baseline 暴露了什么问题、改动了什么假设、用什么独立证据验证、结果怎样传到下一问。

默认优先探索的主线是：

> **从“高分数据”到“高收益数据”：数据价值如何影响算力配置，并最终转化为能力前沿？**

这条线不要求四问全部采用复杂方法。可以只对一个关键机制深入优化，其余部分保持可靠、可解释的 baseline。

## 5. 三条候选研究故事

### 主线 A：从高分数据到高收益数据

**核心问题：** 综合质量评分高的数据，是否也是值得投入算力的数据？

| 问题 | 叙事作用 | 关键证据 |
|---|---|---|
| 第一问 | 发现“表面低分”与“实际低质量”的区别，识别有价值的组合 | 分层原文核验、冲突案例、留出配比收益 |
| 第二问 | 把质量与组合优势转换成单位数据效率和参数替代关系 | 简单模型对照、来源分层、替代区间 |
| 第三问 | 计算好数据是否值得其额外成本 | 固定预算下有/无质量投入的净收益 |
| 第四问 | 检查损失收益能否转成下游能力收益 | 任务桥接、情景前沿差异及区间 |

**推荐组合：** Q1-O1/O2 → Q2-O2/O3 → Q3-O1 → Q4-O2/O3。

**需要避免的跳跃：** A 中数据质量高、B 中半合成质量效应强，不能直接证明历史排行榜提升由数据工程导致。必须保留校准与迁移假设。

**可能的负结果也有价值：** 评分改善了原文解释，却没有带来稳定的配比预测收益。此时故事变为“质量代理与训练价值之间的距离”，明确评分适用边界。

### 主线 B：预算增加时，最值得投入的资源会改变吗

**核心问题：** 何时扩参数，何时增数据，何时提升质量，改变由什么约束触发？

| 问题 | 叙事作用 | 关键证据 |
|---|---|---|
| 第一问 | 确定不同领域的质量、组合效应及供给假设 | 域级质量、稳健配方、映射不确定性 |
| 第二问 | 给出状态相关的边际收益与替代边界 | 交互可辨识性、边际收益图 |
| 第三问 | 找到或排除预算策略转移 | 激活约束、变点区间、搜索稳定性 |
| 第四问 | 分析算力放缓时不同策略的能力后果 | 预算情景与技术效率消融 |

**推荐组合：** Q1-O2/O3 → Q2-O1/O3 → Q3-O2/O3 → Q4-O3。

**启动条件：** baseline 在连续预算轴上确实出现稳定机制，或有数据支持的供给约束。不能为了故事强行加入会制造转移的函数。

**可能的负结果也有价值：** 配置平滑变化、配比不随预算改变。可解释“当前数据与可分离模型不足以支持结构性转移”，并说明需要何种新实验才能区分。

### 主线 C：模型不确定时，最优配置还能相信多少

**核心问题：** 当质量定义、跨源映射和能力桥接均不确定时，哪些资源决策仍然可靠？

| 问题 | 叙事作用 | 关键证据 |
|---|---|---|
| 第一问 | 定量描述评分、样本和域映射不确定性 | 质量区间、排序与配方稳定性 |
| 第二问 | 识别跨源融合中的可辨识与不可辨识部分 | 参数剖面、模型族留出、情景分歧 |
| 第三问 | 比较点最优与稳健配置 | 名义收益代价、压力测试后悔值 |
| 第四问 | 将不确定性传到前沿预测 | 分层预测区间与误差来源分解 |

**推荐组合：** Q1-O3 → Q2-O2 → Q3-O1 → Q4-O1/O3。

**启动条件：** 不同合理 baseline 给出的最优策略有明显差异，或桥接误差与预测提升处于同一量级。

**可能的负结果也有价值：** 不确定性很大，但某些预算下的投入方向始终一致。此时研究贡献是划出稳定决策区域，而不是求一个脆弱的精确最优点。

## 6. baseline 完成后的选题决策

| baseline 发现 | 优先研究 | 不宜采用的表述 |
|---|---|---|
| 质量冲突有清晰、可重复的领域原因 | 主线 A 的质量校准 | “所有专业文本都应加分” |
| 配比交互稳定且跨尺度排序有提升 | 主线 A 的组合价值 | “某领域总是最重要” |
| 质量效应仅由半合成数据支撑 | 条件机制与敏感性研究 | “真实大模型实验已证明” |
| 预算路径有稳定的约束切换 | 主线 B | “三个预算不同，所以发生相变” |
| 所有预算 p* 相同 | 解释可分离结构，或检查有依据的交互 | “优化器不够复杂导致没发现转移” |
| 校准、映射变化导致最优方案翻转 | 主线 C | “选最漂亮的一组参数作为结论” |
| 桥接误差大于预测能力增量 | 主线 C 或任务分层桥接 | “未来将精确提高若干分” |
| 控制模型类型后时间效应消失 | 报告组成变化与归因限制 | “必须存在很高的技术进步贡献” |

最终主线最多选择一个主要机制和一个辅助机制。其余优化作为稳健性检查或未来工作，避免正文变成方法清单。

## 7. 必须保持的逻辑约束

1. **相关不自动变成因果。** 配比实验的证据强度、半合成质量实验、历史排行榜回归不能等同对待。
2. **质量坐标必须贯通。** 第一问 Q 的定义改变后，第二问校准和第三问成本均需重新解释，不能只替换一列数值。
3. **评价目标必须固定。** 不允许改变训练配比时同步改变评价权重，再将目标变容易解释为能力提升。
4. **不重复计算进步。** 已经由 Q、p 或效率变量表示的收益不能完整叠加到时间残差上。
5. **外推需要证据层级。** 估算表一致并不等于真实大模型验证；高可比小模型桥接也不保证高能力区准确。
6. **故事接受被否证。** 没有结构转移、无法区分贡献、某优化无增益，均可形成清晰且有价值的结论。

## 8. 研究阶段的最小实验矩阵

| 实验组 | 只改变什么 | 主要指标 | 回答的问题 |
|---|---|---|---|
| E1 评分消融 | 权重、冲突规则、领域修正 | 核验一致性、域级排名稳定性 | Q 是否更可信？ |
| E2 配比消融 | 线性/交互/非线性 | 留出 RMSE、排序相关、选方后悔值 | 组合价值是否真实可用？ |
| E3 标度律消融 | 无 Q、固定质量效率、有限交互 | 分组留出误差、参数区间 | 扩展是否可辨识？ |
| E4 来源敏感性 | 半合成权重、质量映射、迁移强度 | 参数及最优配置变化 | 结论依赖哪些假设？ |
| E5 资源决策 | 固定质量、联合投入、稳健投入 | 预算可行性、名义/压力测试收益 | 质量投入是否值得？ |
| E6 结构机制 | 成本形状、供给约束、上下文条件 | 激活约束、变点区间 | 转移由什么产生？ |
| E7 能力桥接 | 任务、可比性、模型类型 | 留出误差、区间覆盖 | Loss 收益能否转为能力？ |
| E8 前沿情景 | 预算增长、剩余效率增长 | 时间回测、预测区间 | 放缓情景下哪些结论稳定？ |

不要一次同时更换评分、标度律、优化器和桥接函数后只比较最终能力；那样无法解释改进来自哪里。

## 9. 建议的核心图表

1. 质量冲突案例与域级 Q 对照：显示问题从何而来。
2. 配比响应与跨尺度选方误差：显示数据组合价值的证据。
3. 质量—参数等损失曲线或单位算力边际收益图：连接机制与决策。
4. 连续预算下 N*、D*、Q*、成本份额与激活约束：展示策略是否改变。
5. 逐任务桥接散点及误差带：说明能力转换的可靠范围。
6. 算力放缓情景下的能力前沿与不确定性来源：回答最终问题。

图表中的实测点、半合成点、插值、外推曲线、情景区间使用不同标记，并在图注说明。故事应由这些可检查的证据推进。

## 10. 研究阶段交付标准

- [ ] 一句话主问题与一个可证伪的主要假设。
- [ ] 从 baseline 到优化模型的最小改动说明。
- [ ] 至少一组独立留出验证和必要的消融；证据非独立时明确降级。
- [ ] Q→Loss→预算配置→Benchmark 四段接口一致，误差可追踪。
- [ ] 正结果、负结果、未辨识部分均进入报告。
- [ ] 主图能支撑主张，结论不超过数据来源和外推范围。
- [ ] 各问必用数据要求仍满足，优化没有绕开 baseline 中的困难数据。
- [ ] 所有核心公式、实验结论与引用经团队核验，保留实现与人工审查记录。
