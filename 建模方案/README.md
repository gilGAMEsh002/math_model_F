## 研究总问题

**算力有限时，什么样的数据真正值得投入，数据价值如何随模型规模变化，这种变化又能否解释并预测能力前沿？**

四问依次提供下一问的输入：

```text
全量质量信号、配比实验
    ↓ 第一问：定义质量，识别冲突，估计配比收益
域级 Q、评分规则、配比响应 f(p)、不确定性
    ↓ 第二问：把数据价值转成损失收益
L(N,D,Q,p)、边际收益、参数区间、适用范围
    ↓ 第三问：用真实成本约束选择投入
最优 N、D、Q、p，成本份额，可能的策略转移
    ↓ 第四问：把损失收益转成能力收益
Loss–Benchmark 映射、规模/非规模贡献、情景前沿
```

## 实施顺序

| 阶段 | 任务 | 完成条件 |
|---|---|---|
| P0 | 数据审计与口径冻结 | 全量清单、来源标签、去重规则、单位和切分方案可复核 |
| P1 | 第一问最简 baseline | 全量质量评分、冲突核验、配比检验及接口文件齐备 |
| P2 | 第二问最简 baseline | 经典与质量扩展模型、来源分层验证、可调用预测器齐备 |
| P3 | 第三问最简 baseline | 三档预算、三类成本、C7 上下文情景全部覆盖 |
| P4 | 第四问最简 baseline（条件实施） | 复杂度可控时完成；过高时暂缓并记录待完成范围 |
| P5 | baseline 阶段比较 | 汇总已实施问题的误差和局限；第四问暂缓时明确标记 |
| R | 后续讨论（暂不分配） | baseline 完成后再讨论复杂问题、优化方向和人员安排 |

先完成 P0–P3；P4 复杂度过高时可先不做，直接汇总前三问的阶段结果。复杂扩展与优化方向留待讨论。

## 给后续实施 agent 的任务入口

> 阅读分工表、公共约定和领取的完整 Baseline A/B/C 任务。默认使用干净版数据说明。先完成数据审计，随后实施 baseline，再补齐对照实验。保护原始附件；结果写入对应任务目录。区分实测、半合成、插值、外推和建模假设；报告未满足的数据要求和未辨识参数。本轮优先实现前三问并提交可复现 baseline；第四问若复杂度过高可以先不做并说明待完成项；复杂问题与优化方向仅记录，留待讨论，不自动开展。不得预设质量总是最优、必有结构性转移、非规模因素必然占主导等结论。

- 方案依据与已核验的文件事实记录于实施计划。后续数据变化时重新生成审计表，以实际文件为准。
