## 研究总问题

**算力有限时，什么样的数据真正值得投入，数据价值如何随模型规模变化，这种变化又能否解释并预测能力前沿？**

四问依次提供下一问的输入：

```text
全量质量信号、配比实验
    ↓ 第一问：定义质量，识别冲突，估计配比收益
域级 Q、评分规则、配比响应 f(p)、不确定性
    ↓ 第二问：把数据价值转成损失收益
L(N,D,Q,p)、边际收益、参数区间、适用范围
    ↓ 第三问：用真实成本约束选择投入
最优 N、D、Q、p，成本份额，可能的策略转移
    ↓ 第四问：把损失收益转成能力收益
Loss–Benchmark 映射、规模/非规模贡献、情景前沿
```

## 实施顺序

| 阶段 | 任务 | 完成条件 |
|---|---|---|
| P0 | 数据审计与口径冻结 | 全量清单、来源标签、去重规则、单位和切分方案可复核 |
| P1 | 第一问最简 baseline | 全量质量评分、冲突核验、配比检验及接口文件齐备 |
| P2 | 第二问最简 baseline | 经典与质量扩展模型、来源分层验证、可调用预测器齐备 |
| P3 | 第三问最简 baseline | 三档预算、三类成本、C7 上下文情景全部覆盖 |
| P4 | 第四问最简 baseline | 逐任务分析、桥接、贡献分解及前沿预测闭环 |
| P5 | baseline 比较 | 各问对照方法完成，误差与敏感性集中汇总 |
| R | 研究型优化 | 根据 P0–P5 的证据，从优化文档选择一条主线 |

先跑通 P0–P4，再完成 P5。不得为了更换算法而长期阻塞四问接口。

## 给后续实施 agent 的任务入口

> 阅读分工表、公共约定和领取的独立任务卡。默认使用干净版数据说明。先完成数据审计，随后实施 baseline，再补齐对照实验。保护原始附件；结果写入对应任务目录。区分实测、半合成、插值、外推和建模假设；报告未满足的数据要求和未辨识参数。先提交能完整复现的 baseline 报告，再依据证据提出优化方案。不得预设质量总是最优、必有结构性转移、非规模因素必然占主导等结论。

## 范围与证据

- 本轮文档整理没有运行模型训练、标度律拟合或资源优化，不提供虚构的质量分、拟合优度或最优参数。
- 题面明确要求优先。原始附件说明中的低可见度附加建议已在干净版中删除；正常正文未改写，复现与核验见清洗记录。
- 题面包含 AI 使用与披露要求。后续团队应核验核心建模与推导，记录 agent 的使用环节、贡献和人工审查；本目录不替代正式文献或实验证据。
- 方案依据与已核验的文件事实记录于实施计划。后续数据变化时重新生成审计表，以实际文件为准。
