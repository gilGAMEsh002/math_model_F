# Baseline 公共约定与接口

本文件是所有独立任务卡的共同依赖。具体数据清单、公式和验收规则以[完整实施计划](../01_问题分析与Baseline实施计划.md)为准。

## 统一规则

1. 使用仓库根目录的 `数据说明_干净版.pdf`；原始 PDF 仅用于来源审计。
2. A1–A3 全量处理，按域与 id 审计重复；各来源分别统计，合并时去重。
3. 质量字典、固定评价权重 v、域映射、数据切分和单位由共享配置冻结。
4. 真实观测、半合成、插值、估算和子集分层报告；不把表格样本数当作独立实验数。
5. N、D 成本计算使用实际参数数/Token 数；不同 Q 坐标之间的映射显式保存。
6. A6–A11 是最终检验集；调参使用 A4/A5 内部验证。未来时间的数据不得用于过去预测的拟合。
7. baseline 对比先固定同一上游输入，再更换当前模型；端到端 A/B/C 链条的差异不能直接归因于某一个算法。
8. 各 baseline 已实施的部分必须满足对应问题的数据要求；第四问复杂度过高时可整体暂缓，并明确其待完成状态。共享清洗和逐任务分析可以复用，但报告必须引用其版本和结果。

## 共用产物与协商规则

以下只是建议的复用接口，不构成额外的人员分工或长期维护任务。

| 产物 | 内容 | 使用方 |
|---|---|---|
| `configs/shared/` | 数据字典、切分、单位、列序 | 三条 baseline |
| `artifacts/shared/q1/` | 质量、域映射、配比预测器 | 第二问及以后 |
| `artifacts/shared/q2/` | 损失函数、导数、情景与适用范围 | 第三、四问 |
| `artifacts/shared/q3/` | 优化情景与共同配置结果 | 第四问 |
| `artifacts/shared/q4/` | C 表清洗、C8 聚合、桥接和日期口径 | 第四问 |

三人可协商复用已有成果，记录配置哈希、模型版本和来源。单条路线不必等待其他人的全部模型完成；可先用本路线产物跑通。没有共用版本时分别保存，比较前核对口径，不静默混用。

## 当前工作边界

每人只负责一条完整 baseline。上述数据接口不自动指派额外负责人；复杂研究、具体优化方向、深度模型扩展和长期维护安排均待讨论。已实施问题的基本数据与验证要求仍须满足；第四问可因复杂度暂缓，不作为前三问阶段性交付的阻塞项。

## 每份结果的最小元数据

`baseline_id`、配置哈希、上游版本、数据来源及哈希、训练/验证/检验样本量、随机种子、软件环境、运行命令、指标定义、外推标记和区间生成方法。

先完成完整实施计划中的 P0，再运行各任务卡。最小有意义的测试沿用总计划第 6 节。
