# Q3-C：候选配比与局部联合优化

## 任务归属

- 建议负责人：成员丙（占位称呼，可在分工表改为姓名）。
- 状态：待实施；当前文档不表示实验已完成。
- 所属问题：第 3 问。
- 公共规范：[公共约定与接口](./00_公共约定与接口.md)。
- 整体上下文：[问题分析与完整实施计划](../01_问题分析与Baseline实施计划.md)。
- 分工与依赖：[三人分工与交接](../三人分工与交接.md)。

## 输入与前置依赖

冻结的 Q2 模型；Q1 训练数据选出的候选配比；C7。

公共切分、指标、来源标签和单位必须与其他 baseline 一致；所用上游模型版本记入配置。上游尚未发布时可以实现接口和解析案例，但不得用模拟结果冒充最终数据实验。

## 模型与实现步骤

枚举可信候选 p，对每个 p 运行 Q3-B；有必要时使用多起点 SLSQP 细调。

1. 候选仅从训练信息或既定可信区域生成，不用最终检验 Loss 偷选配方。
2. 明确 Q0 是否依赖 p，先运行固定 Q0 基线，再把关联设定作单独情景。
3. 复用 Q3-B 的预算与成本计算，对每个候选搜索 N、Q，并输出各候选误差与成本。
4. 连续优化 p 时限制单纯形、可信区域和起点；与枚举结果交叉核验，标注局部解。

## 验证与完成条件

检查最优 p 是否随预算变化；完全可分离 h(p) 下 p 不变可能是正确结果，不应强求转移。

- [ ] 对应问题的必用数据要求全部落实，或逐项解释限制。
- [ ] 按公共协议完成留出验证、消融和必要的数值核验。
- [ ] 配置、随机种子、环境、输入哈希和上游版本可复现。
- [ ] 正结果、负结果、失败与外推边界均记录。
