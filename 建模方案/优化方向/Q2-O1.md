# Q2-O1：检验“质量收益是否随规模变化”

- 建议负责人：成员乙；具体排期见[三人分工与交接](../三人分工与交接.md)。
- 状态：待 baseline 证据筛选，未启动实验。
- 本方向对应第 2 问；先阅读该问的 [baseline 索引](../baselines/README.md)。
- 研究总线、消融矩阵与交付规范：[优化方向与研究主线](../02_优化方向与研究主线.md)。

**动机。** Q2-B 假设同样的质量改善通过固定 κ 影响有效数据量。这未必覆盖不同规模模型利用复杂数据的差异。

**研究假设。** 质量提升的收益可能取决于模型规模或数据量，且这种交互具有边界或饱和性。

**具体改进。**

- 从单一交互开始，例如让质量效率指数在有界函数下依赖 log N，避免高次多项式无限外推。
- 也可比较 Q2-C 的参数效率通道，但不要同时增加多组无法辨识的交互。
- 检验单调性、边际收益递减及质量—参数替代曲线的形状。
- 将参数充分性、置信区间和外推稳定性作为选择标准，而非只看拟合误差。

**验证与消融。** 无质量、固定质量效率、规模相关质量效率三层比较，按 N 分组留出。质量数据来自半合成，结论必须限定为“附件设定下支持的交互”，不能宣传为新发现的真实训练定律。

**传给下一问。** 若交互可辨识，第三问可以检验不同预算下质量投入是否改变；若无法辨识，应报告转移对该假设的依赖。

**降级条件。** 交互的收益仅存在于同一生成机制的半合成数据、对参数扰动不稳定时，保留情景分析，不提升为主实证结论。
