# Q2-O3：研究稳定的替代边界，而非单一弹性数值

- 建议负责人：成员甲；具体排期见[三人分工与交接](../三人分工与交接.md)。
- 状态：待 baseline 证据筛选，未启动实验。
- 本方向对应第 2 问；先阅读该问的 [baseline 索引](../baselines/README.md)。
- 研究总线、消融矩阵与交付规范：[优化方向与研究主线](../02_优化方向与研究主线.md)。

**动机。** “提升质量相当于增加多少参数”与当前 N、D、Q 有关，有时仅增加参数无法达到同等收益。

**研究假设。** 质量、参数和数据之间存在状态相关的替代边界；不同预测模型对某些区域的建议一致，对另一些区域分歧明显。

**具体改进。**

- 绘制 N–Q 等损失曲线、有限参数替代可行区、单位算力边际收益差。
- 用参数重采样和不同模型形式构建替代率区间。
- 加入配比可行方向的局部替代分析，并识别受数据供给约束的调整。
- 比较总 Loss 与可约 Loss 弹性，解释不可约项如何改变“收益大小”的表象。

**验证与消融。** 导数和有限差分交叉校验；针对若干参考点检查等效公式返回的 Loss 是否一致；外推区与观测支持区分开画。

**传给下一问。** 第三问的策略分区由边际收益和成本共同决定，有明确机制支撑。

**降级条件。** 替代率跨模型变化过大时，只报告收益排序稳定区域，避免给出过度精确的兑换比例。
