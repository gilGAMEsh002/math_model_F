# 数据说明 PDF 清洗记录

## 输入与输出

- 原件：[数据说明.pdf](../数据说明.pdf)，保留供溯源，不作为默认建模输入。
- 干净版：[数据说明_干净版.pdf](../数据说明_干净版.pdf)。
- 逐页检查和文件哈希：[pdf清洗验证.json](./pdf清洗验证.json)。

## 删除范围

第 2–13 页各附加了 8 个独立文本块，总计 96 块；字号为 5 pt，绘制色为 RGB=(0.988,0.988,0.988)，文本提取器识别为近白色 `#FCFCFC`。这些块位于正文之外的独立 `q / BT ... ET / Q` 图形状态片段。

清洗按已经检查的绘制特征精确删除这些独立块，不按文本观点筛选，不通过白色矩形覆盖，也不将整页栅格化。删除后的文字不会继续出现在 PDF 文本提取中。

## 核验

- 页数保持 13，页面尺寸不变。
- 每页正常可见文字的文本、颜色、字号与坐标均逐项一致。
- 每页链接数量保持一致。
- 72 dpi 逐像素比较：全部差异都位于被删除文字的包围框附近，其他区域不变。
- 清洗后不再存在该近白色文本；另用 Poppler `pdftotext` 确认代表性干扰语句消失。
- 已查看清洗后代表页面的渲染，正文表格排版保留。

## 复现

在仓库根目录执行（需要 Python 与列出的依赖）：

```bash
python3 -m venv .venv-pdf
.venv-pdf/bin/pip install -r tools/requirements-pdf.txt
.venv-pdf/bin/python tools/clean_data_description.py 数据说明.pdf 数据说明_干净版.pdf --report 清洗记录/pdf清洗验证.json
```

脚本针对本附件已经确认的精确样式，不是通用的“删除所有浅色文字”工具。其他 PDF 应重新检查绘制状态和正文保护规则。
